## [CSED211]컴퓨터 SW시스템 개론

- 수업

- 과제

    - cachelab: 캐쉬를 SW로 구현하는 과제 + matrix 연산에 대한 최적화
    - shelllab: 간단한 쉘 만들기
    - malloclab: malloc 구현해요

- 근데 저는 다른 과목에 교통사고 당해서 별 생각없이 사고를 받아들임.

## [CSED332]소프트웨어 설계 방법
- 교수: 배경민 교수님
- 수업
    - 소프트웨어를 설계하는 방법, 과정, 다양한 테크닉 등을 배웁니다.
    - 소프트웨어 테스트 소위 QA라고 하는 과정들을 어떻게 진행할 수 있는지 주로 Unit Test 위주로 배워요.
- 과제
    - 처음 3개의 과제는 기본적인 자바 프로그래밍이었습니다.
    - 과제들은 수업을 위해 생성된 깃랩 레포에 업로드하는 방식으로 진행되며 당연히 깃을 사용합니다.
    - 수업에서 사용한 개념들을 녹여서 과제를 진행할 수 있습니다.
        - 자바는 객기부리지 말고 JetBrain IntelliJ 사용합시다. 도저히 안되겠음.
        - 학교 이멜로 인증하면 JetBrain 풀셋 라이센스 줍니다. 애용하도록.
        - 자바는 버전들이 많아서 바로 설치하기 좀 꺼려했는데, [sdkman](https://sdkman.io/) 설치해서 사용하면 노드의 npm 사용하는 것처럼 편하게 버전 관리할 수 있습니다. Gradle도 버전 설정 가능해서 사용하면 편했어요.
    - 마지막 과제는 팀 프로젝트입니다. 저희는 7명인가 되었어요. IntelliJ 플러그인 만들기였습니다.
    - 다만 배웠던 소프트웨어 개발 과정들을 녹여내면서 "애자일"한 과정을 거쳐 TDD 기반의 소프트웨어 개발 과정을 보여주어야 했습니다. 이 때문에 로드가 기하급수적으로 올라갈 수 있는데, 팀원 잘 만난다면 정말 재밌게 잘 할 수 있습니다.
    - 좋은 팀원을 만나 즐거운 프로젝트 했습니다

## [CSED490C]컴퓨터공학특강: 이종 병렬 컴퓨팅
- 교수: 성효진 교수님
- 교수님이 다른 곳으로 가셔서 이제 못듣는 과목이지만 병렬 컴퓨팅 이름으로 김광선 교수님의 다른 강의가 열립니다. 그거랑 거의 같다고 알고 있어요.
- Low-Level의 CUDA 프로그래밍을 통해서 여러 연산을 병렬로 연산하는 방법에 대해 배우고 이를 최적화하는 방법을 공부합니다.
- 과제는 배웠던 최적화된 병렬 처리 알고리즘을 구현하고 이에 대한 실험을 하는 내용입니다.
- 저는 맥이라 학과 클러스터 사용해서 과제 진행했고, nvidia-cuda 도커 이용해서 진행했습니다.
- 마지막 프로젝트는 수업시간에 다루지 않은 주제를 이용해 계산을 최적화하는 프로젝트입니다.
- 2주마다 과제가 나와서 로드가 꽤나 있는 편이지만, 재밌었어요.
